# INDUSTRY KICK 0.7.0

INDUSTRY KICK by 909VOLTS is a Windows VST3 instrument for hard-techno and industrial kicks.

## Install

1. Close Ableton Live and any other VST host.
2. Open `Windows` and run `INDUSTRY-KICK-Setup-Windows-x64.exe` as administrator.
3. Reopen the host and rescan VST3 plugins.

The installer uses `C:\Program Files\Common Files\VST3` and preserves existing user presets.

## Package contents

- `Windows` — installer, standalone build and VST3 bundle.
- `Documentation` — English user manual.
- `Legal` — draft software EULA and release checklist.
- `Source` — C++/JUCE source and build files.

Windows 10/11 x64 and a 64-bit VST3 host are required. The development installer is not digitally signed.
